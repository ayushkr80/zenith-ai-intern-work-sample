# StylePilot — AI Fashion Recommendation POC

Independent work sample for the Zenith/J.E.R.K. AI internship assignment.

## What it demonstrates
- Context-aware recommendations
- Colour-profile-aware palettes
- Occasion + climate adaptation
- Budget-aware positioning
- Structured user feedback for a future personalization loop

## Run
pip install -r requirements.txt
streamlit run app.py

This is an independent proof-of-concept. It does not claim to reproduce proprietary Zenith/J.E.R.K. models, datasets or internal architecture.
